Classical Search (BFS)

BFS explores neighbor nodes first, before moving to the next level neighbors. It guarantees the shortest path in an unweighted grid but can be slow and memory-intensive.

Complexity: O(N) where N is the number of nodes.

Quantum-Inspired Search

Simulates quantum superposition and parallel exploration. It evaluates multiple paths simultaneously, utilizing interference-like patterns to amplify the probability of finding the exit faster.

Complexity: O(√N) (Simulated Grover's Speedup).
